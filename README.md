# Last One

Last One es un juego de cartas creado con Electron. Este proyecto está abierto a la comunidad: se agradecen ideas, reportes de errores y contribuciones para mejorarlo.

## Empezar

Necesitas Node.js y npm instalados. En la carpeta del proyecto, ejecuta:

```bash
npm install
npm start
```

## Contribuir

Puedes abrir un issue para proponer cambios o reportar un problema, o enviar un pull request con tu contribución. Si vas a hacer cambios grandes, abre primero un issue para comentarlos.
